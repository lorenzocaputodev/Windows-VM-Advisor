Windows-VM-Advisor - VM Profiles
================================

Use these settings as a practical starting point. Increase them only if needed.

Best choices:
- Windows 11 [Recommended]
   Hypervisor: VMware Workstation
   Suggested setup: 4 vCPU, 8192 MB RAM, 100 GB disk, UEFI, Secure Boot Enabled, TPM Yes, Network NAT
   Save VM files on: D:
   Notes: Current free RAM is tighter than ideal for this starting profile. Close other applications before starting the VM.; Enable the virtual TPM and Secure Boot in the hypervisor VM settings; the host TPM is not required.

- Linux Mint [Recommended]
   Hypervisor: VMware Workstation
   Suggested setup: 2 vCPU, 4096 MB RAM, 48 GB disk, UEFI, Secure Boot Disabled, TPM No, Network NAT
   Save VM files on: D:

- Ubuntu LTS [Recommended]
   Hypervisor: VMware Workstation
   Suggested setup: 2 vCPU, 4096 MB RAM, 48 GB disk, UEFI, Secure Boot Disabled, TPM No, Network NAT
   Save VM files on: D:
